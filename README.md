✈️ TK Travel
Sistema web desenvolvido como projeto acadêmico para uma agência de viagens, com o objetivo de aproximar clientes da agência e facilitar a divulgação e administração de pacotes e promoções.

A plataforma permite que os visitantes conheçam os serviços e oportunidades oferecidos pela agência, demonstrem interesse através da geração de leads e sejam direcionados para atendimento pelo WhatsApp.

💻 Funcionalidades
🌎 Visualização de informações da agência
🧳 Divulgação de pacotes de viagem
🏷️ Gerenciamento de promoções
👥 Cadastro e gerenciamento de leads interessados
💬 Recursos de comunicação com o cliente
📱 Direcionamento para atendimento via WhatsApp
⚙️ Área para administração das informações da plataforma
🛠️ Tecnologias utilizadas
C#
ASP.NET Core MVC
Entity Framework Core
SQL Server
HTML
CSS
JavaScript
Bootstrap
🎓 Sobre o projeto

O TK Travel foi desenvolvido durante a faculdade como projeto acadêmico, aplicando conceitos de desenvolvimento web, arquitetura MVC, banco de dados e criação de funcionalidades voltadas para uma situação real de negócio.

O projeto busca simular uma solução digital para uma agência de viagens, reunindo divulgação de pacotes, captação de potenciais clientes e ferramentas para gerenciamento das informações apresentadas na plataforma.
